# Quick Start

Goal of this page:

> Start from zero, run the first segmentation example locally, and see the output.

---

## 1. Prerequisites

You will need:

- Python 3.8 or later
- `git` (optional but convenient)

---

## 2. Clone the repository and install dependencies

In your terminal:

```bash
git clone https://github.com/lxl-max/image-segmentation.git
cd image-segmentation

# Option A: if a requirements.txt exists
pip install -r requirements.txt

# Option B: minimal install (adjust if needed)
# pip install numpy matplotlib opencv-contrib-python
